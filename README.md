# 呼吸康复吹气训练小程序（个人测试版）

> **给用户的微信小程序体验版** —— 手机麦克风吹气检测 + 蜡烛游戏化反馈 + 个人基线评估 + 历史趋势追踪。
> 纯自用、不发布、无后端，数据全部存储于手机本地。

## 一句话定位

**非医疗器械的家庭呼吸训练辅助工具**：用户对手机吹气，小程序实时计算分贝与时长，用蜡烛动画即时反馈，首次使用完成"三口气基线测试"建立个人基准，之后每次训练自动对照基准与循证康复指导，生成"比上次/比基线进步/退步"的趋势反馈。

## 目标用户

- **主用户**：用户（ICU 转出康复期）
- **使用者**：用户本人 + 家属辅导使用
- **排除**：不面向医疗机构、不发布、不收集任何他人数据

| 项 | 选择 |
|----|------|

## 功能总览（MVP）

1. **用户档案**：首次进入填写——健康人/病人、年龄、性别、原发病、手术/ICU 经历、康复阶段
2. **康复周期 Session**：可多次新建周期；**每个周期重新录制基线**；档案快照随周期存档
3. **基线测试**（每周期首次）：轻吹 / 普通吹 / 劲吹 三口气 × 3 次重复，基于档案规则表生成**相对自身参考值**，判定"强/中/弱"；允许跳过（围手术期/ICU 后康复建议完成，补录后追溯补算）
4. **四种训练模式**：蜡烛模式 / 持久模式 / 节奏模式 / 自由模式
5. **实时反馈**：分贝值 + 蜡烛动画（<40dB 不动 / 40-60 微摇 / 60-80 大摇 / 80-100 灭一根 / >100 全灭）
6. **历史趋势**：训练记录列表 + 折线图，每次训练记录**相对当前周期基线的差值**
7. **循证对照**：基于 Post-ICU 康复方案（SCCM 2024 指南等）给出"今天比昨天"与"比基线"的进步提示
